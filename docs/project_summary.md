Originally, our ERS backend was built in Javalin, meaning us as developers had to handle every connection, write every query through JDBC, handle every service/repository/controller instance, and register every Javalin route, from request to response. Migrating the backend through Spring Boot means we can take advantage of Spring-controlled beans and injections, automatically doing the setup for us. We get access to the whole ecosystem, including Spring Data JPA, mapping entities to the database, writing many of the CRUD queries for us, with validation integration with Jakarta. We used Spring MVC to handle mapping routes and Jackson serialization of request bodies. In the first iteration, we handled authentication with sessions, but Spring Security offers us robust configuration and protection of our endpoints through the SecurityFilters, and we implemented stateless JWT with a Bearer Token pattern for authorization. Finally, we implemented global exception handling with @RestControllerAdvice, with @ExceptionHandler for custom exceptions for erroneous situations that required precise handling.
